# 场景提示词检查

场景 Agent 编译的是已确定的视觉规格。先把最影响画面的事实写清，再让具体模型处理渲染细节。

## 审稿顺序

- **故事作用：** 观众能否从场景看出故事发生在哪里，以及关键动作需要哪些实体与空间？
- **空间：** 地面、家具、墙、入口、路径和关键道具能否同时成立？留位是否足以容纳真实商品和人物？
- **材质：** 重要物体有明确基材、表面处理、光泽、边缘和使用状态吗？“木质或塑料”“清漆或木蜡油”等二选一要由美术规格先决定。
- **光线：** 光从环境中哪个真实位置来？物体的反射与阴影是否和该材质相符？纯背景不要预画未出现商品的投影。
- **连续性：** 同一个场景的结构、材质、窗位和固定道具保持一致；损坏、天气或时间变化有明确的前后状态。
- **来源：** 商品身份来自 Koma 商品图，人物身份来自人物参考资产，已选视觉卡片来自 `style_cards`。场景提示词只写环境，不补商品结构、标识、卖点或未证实的玩法。
- **控制：** 导演指定的画幅、镜头和视角照办；未指定时保持可用空间，不自行决定镜头数或相机轨迹。描述可见结果，少用“高级、电影感、震撼、8K”等无法验收的词。

## 假设性的写法示例

若美术指导已选定“儿童房夜里，玩具车将木质积木搬回右侧塔楼”，纯背景提示词可以写：

> 同一间儿童房的夜间桌面。浅色木质积木城堡位于桌面中央，主体塔楼仍完整，右侧塔楼倒塌；圆润的方块与三角块有细木纹和轻微磨损，散落在城堡右前方，形成一条连续、平整的通路。窗在桌面靠外墙一侧，冷色夜光沿积木边缘形成柔和阴影，床头暖色小夜灯只照亮桌面一角。城堡形制、散落块的位置与既定白天场景相同。通路与城堡前方保留真实玩具车的合成空间；背景里没有车、人物或车的接触阴影。

这只是材料与空间完整度的示例。真实任务应服从当前故事、美术规格、商品图片和导演镜头要求，不能复用示例中的木材、儿童房或光线。
