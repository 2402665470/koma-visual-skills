# 视觉设定要求

此文件用于把故事里的名词写成可见、可制作的画面。按资产的重要程度选择细节，不把下面各项机械填满。

## 场景需求

- **故事作用与使用范围：** 哪些段落或已有镜头需要它，人物和商品在此做什么，观众应先注意什么。
- **空间与尺度：** 地面／墙面／远景如何连接；入口、通道、主要物体和人物／商品的相对尺寸；视角变化时仍成立的地理关系。
- **形态与材质：** 关键建筑、家具或道具的几何形态、构造方法、基材、表面处理、粗糙或反光程度、透明度、边缘状态、磨损与破损方式。材质选择应说明为何适合故事与商品。
- **色彩与光：** 主色、辅色、商品或人物的辨识对比；场内可解释的光源、方向、软硬、阴影、反射和时间变化。
- **故事状态：** 哪些物体在前后镜头中保持不变，哪些因动作改变，改变前后具体是什么样。
- **合成接口：** 商品实拍图需要的留白、接触面、遮挡关系、透视、反射与阴影条件；场景背景不代替真实商品身份参考。

## 人物需求

从导演故事中已存在的人物出发。身份锚点包括可辨识的年龄感、体态、脸部／发型特征、服装轮廓与材质、代表性色彩或配件；镜头状态包括姿势、表情、手部动作、衣物变化和所处光照。给生成人物的 Agent 标明参考图中哪些特征必须沿用，哪些可以随故事变化。涉及儿童时，外观要符合故事年龄与行动能力，不靠成人化造型制造“高级感”。

## 商品融入需求

先列出实拍图能证实的商品外观事实，再说明商品在该场景里的用途、接触对象、相对尺度、位置、可见面和与人物的交互。选定让商品属于这个世界的材质与光照联系，但不要改变商品本身的结构、颜色、标识或功能。素材不能证实的细节标为未知。

## 给下游 Agent 的每项交付

1. 资产名称及故事／镜头用途，现有实体或素材引用。
2. 一段连贯、具象、可直接作为生成提示词主体的视觉描述；把最重要的形态、材料、光和空间关系写进句子，而非只列标签。
3. 参考图各自的用途：商品身份、人物身份、场景结构、材质或仅作气氛。互相冲突的参考要指出优先级。
4. 必须保持的锚点、允许探索的部分、前后状态、商品合成接口。
5. 可观察的验收条件，以及尚未确认的导演决策。

场景／人物生成 Agent 负责结合具体模型、参数与失败反馈写最终提示词；美术指导负责审查产物是否实现既定视觉设定。发生执行偏差时反馈观察到的差异，不用“再高级一点”作为返工意见。

## 非默认示例：夜间修复积木城堡

若导演已确定“白天孩子碰倒城堡，夜间玩具车修复”，美术指导需要**选择并写定**城堡材质，而不能只写“积木城堡”。一种可辩护的设定是：城堡由浅色木质积木堆叠，块体边缘圆润，表面可见细木纹和轻微使用痕迹；右侧塔楼倒塌，散落块体沿桌面形成玩具车可通行的修复路径。夜间主光来自窗外冷月光，桌面局部受暖色小夜灯照亮；白天和夜间共用同一城堡结构及损坏位置。若商品是玩具车，车身外观必须来自真实商品图，场景为它预留路面、尺度和接触阴影，不能提前生成另一辆虚构车。选择木质积木只是此例的美术判断，其他故事或商品可能需要塑料拼插、纸板或金属模型。

这个例子说明细节的判断标准：材质及构造会影响破损方式、光照反应、玩具车的行动尺度与跨镜头连续性，因此必须定下来；远处看不见且不参与故事的摆件可以留给场景 Agent 探索。
